# 111 Days of Learning — AI/ML

All that I have learnt and practiced about AI and ML using Python, as part of my **111 Days of Learning** challenge conducted by **Code for Change Nepal (CFC)**.

## Progress

🟢 **90 / 111 days completed**
⬜ Days 91–111 remaining

## About

This repository is a daily log of hands-on AI/ML practice — one focused Python file per day, moving from programming and math foundations through classical ML, deep learning, reinforcement learning, and into modern NLP / Generative AI tooling.

## Journey Breakdown

### Days 1–9 — Foundations
Python revision, classes/inheritance/polymorphism, NumPy & Pandas practice, statistics, calculus, probability & normalization.

### Days 10–20 — Data Analysis & Visualization
Pie charts, data drawing, and a full Titanic dataset walkthrough — analysis, visualization, cleaning, and feature engineering leading into a first ML model.

### Days 21–32 — Classical Machine Learning
Linear regression (from scratch), logistic regression, decision trees (California house price prediction), random forest, SVM, KNN, Naive Bayes, cross-validation & hyperparameter tuning, pipelines & preprocessing.

### Days 33–38 — Unsupervised Learning & Project Flow
Feature engineering, imbalanced data handling, model evaluation metrics, dimensionality reduction (PCA), k-means clustering, hierarchical clustering & DBSCAN, model saving, end-to-end ML project flow, time series analysis.

### Days 39–73 — Deep Learning *(CNNs, RNNs/LSTMs)*
Neural network fundamentals, CNNs (filters, image classification), RNNs/LSTMs in PyTorch.

### Days 74–80 — Reinforcement Learning
RL fundamentals, Q-learning, DQN, policy gradient methods, OpenAI Gym projects.

### Days 81–90 — NLP & Generative AI
Transfer learning, RoBERTa, LoRA, RAG (Retrieval-Augmented Generation), LangChain, AI agents, vector databases, Streamlit & Gradio app-building, MLflow.
